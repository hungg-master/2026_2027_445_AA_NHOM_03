# SmartTrial backend

Laravel 12/Sanctum. Xem [hướng dẫn chạy và cấu hình đầy đủ](../README.md) trước khi cài đặt hoặc nâng cấp database.

Kiểm tra trong thư mục này:

```sh
php artisan test
php artisan route:list --path=api
```

Khóa LiveKit, SMTP và AI chỉ cấu hình ở backend. Thanh toán hiện dùng chế độ TEST, chưa kết nối cổng thu tiền thật. Kết quả kiểm chứng và giới hạn thực tế ghi tại [báo cáo hoàn thiện](../BAO_CAO_HOAN_THIEN_CODE.md).
